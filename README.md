| Файл | Описание |

### Голос

Да — JARVIS **говорит** нейросетевым голосом (edge-tts):
- 🇷🇺 `ru-RU-DmitryNeural`
- 🇬🇧 `en-GB-RyanNeural` (британский мужской, стиль butler)

Нужен интернет для нейро-голоса; без сети — системный SAPI.

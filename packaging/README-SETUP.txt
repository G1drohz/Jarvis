JARVIS — установка
==================

1. Распакуй этот архив
2. Запусти setup.bat (двойной клик)
3. Дождись окончания — установщик:
   - поставит Python 3.11, если его нет
   - скачает JARVIS
   - установит зависимости
   - создаст ярлыки на рабочем столе и в меню Пуск

Папка установки:
  %LOCALAPPDATA%\Programs\JARVIS

Удаление:
  %LOCALAPPDATA%\Programs\JARVIS\uninstall.bat

Альтернатива без установки Python:
  скачай portable-сборку JARVIS-Portable-*.zip из Releases
  и запусти JARVIS.exe
